## What the App Does

The Flutter app is the **parents' window into their child's school life**. Parents install it on Android (and iOS, when published) and use it for:

| Feature | What the parent sees |
|---|---|
| 🏠 **Dashboard** | Greeting, live clock, action cards, latest announcements |
| 🚪 **Gate Status** | Is my child currently inside school? Full IN/OUT history |
| ✅ **Attendance** | Daily attendance with present/absent/late status |
| 📊 **Results** | Per-term grades for each module + computed letter grade |
| 💬 **Messages** | Two-way chat with the child's teachers |
| 📢 **Notices** | School-wide and class-specific announcements |
| 🤖 **Chatbot** | RAG-powered Q&A over school policies |
| 🙋 **Support** | File complaints/suggestions, track status |
| 🔍 **Lost & Found** | Browse found items |
| 🔔 **Notifications** | History of FCM push messages |
| ⚙️ **Settings** | Theme, biometric toggle, logout |
| 👤 **Profile** | Parent info + child info + teacher info |

> Staff (admin/teacher/security) do **not** use this app — they use the Next.js web frontend.

## Architecture — MVVM in Practice

Every feature follows the same shape:

```
features/<feature>/
├── models/                  ← Pure Dart classes (data only)
├── repositories/            ← API-talking layer (Dio calls + JSON parsing)
├── viewmodels/              ← extends ChangeNotifier (state + methods + notifyListeners)
└── views/                   ← Widget tree (consumes ViewModel via Provider)
```

### Why MVVM?

- **Testable:** Repositories can be mocked. ViewModels are plain Dart.
- **Separation:** UI doesn't call Dio. ViewModel doesn't know about widgets.
- **Reactive:** `notifyListeners()` triggers UI rebuild.

### Example — `attendance` feature

#### Model

```dart

  final DateTime date;
  final String status;           // present | absent | late | excused

  final String? markedByName;

  AttendanceRecordModel.fromJson(Map<String, dynamic> json)
    : id = json['id'],
      date = DateTime.parse(json['date']),
      status = json['status'],
      remarks = json['remarks'],
      markedByName = json['marked_by']?['full_name'];

  final int total;
  final int page;

```

#### Repository

```dart
// features/attendance/repositories/attendance_repository.dart
class AttendanceRepository {
  final ApiClient _api;
  AttendanceRepository(this._api);

  Future<AttendanceResponseModel> getMyChildAttendance({
    required int page,
    required int limit,
  }) async {
    final res = await _api.dio.get(
      '/api/attendance/my-child',
      queryParameters: {'page': page, 'limit': limit},
    );
    return AttendanceResponseModel.fromJson(res.data['data']);
  }
}
```

#### ViewModel

```dart
// features/attendance/viewmodels/attendance_viewmodel.dart
class AttendanceViewModel extends BaseViewModel {
  final AttendanceRepository _repo;
  AttendanceViewModel(this._repo);

  final List<AttendanceRecordModel> records = [];
  int _page = 1;
  bool hasMore = true;

  Future<void> load({bool refresh = false}) async {
    if (refresh) { _page = 1; records.clear(); hasMore = true; }
    if (!hasMore) return;
    setLoading(true);
    try {
      final res = await _repo.getMyChildAttendance(page: _page, limit: 20);
      records.addAll(res.records);
      hasMore = records.length < res.total;
      _page++;
      setError(null);
    } catch (e) {
      setError(e.toString());
    } finally {
      setLoading(false);
      notifyListeners();
    }
  }

  Future<void> refresh() => load(refresh: true);
  Future<void> loadMore() => load();
}
```

#### View

```dart
// features/attendance/views/attendance_screen.dart
class AttendanceScreen extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Consumer<AttendanceViewModel>(
      builder: (context, vm, _) {
        if (vm.isLoading && vm.records.isEmpty) return CircularProgressIndicator();
        if (vm.error != null) return ErrorView(vm.error!);
        return RefreshIndicator(
          onRefresh: vm.refresh,
          child: ListView.builder(
            itemCount: vm.records.length + (vm.hasMore ? 1 : 0),
            itemBuilder: (ctx, i) {
              if (i == vm.records.length) {
                vm.loadMore();
                return Center(child: CircularProgressIndicator());
              }
              return AttendanceTile(record: vm.records[i]);
            },
          ),
        );
      },
    );
  }
}
```

## Networking Layer (Dio)

### `ApiClient` — `core/api/api_client.dart`

```dart
class ApiClient {
  late final Dio dio;
  final SecureStorage _secureStorage;

  ApiClient(this._secureStorage) {
    dio = Dio(BaseOptions(
      baseUrl: ApiConfig.baseUrl,
      connectTimeout: Duration(seconds: 20),
      receiveTimeout: Duration(seconds: 20),
      sendTimeout: Duration(seconds: 20),
      headers: {'Content-Type': 'application/json'},
    ));

    dio.interceptors.add(InterceptorsWrapper(
      onRequest: (options, handler) async {
        final token = await _secureStorage.getAccessToken();
        if (token != null) {
          options.headers['Authorization'] = 'Bearer $token';
        }
        return handler.next(options);
      },
      onError: (err, handler) {
        // 401 → broadcast "logout" event (clear stored token, push to /login)
        return handler.next(err);
      },
    ));
  }
}
```

### Error Handling Pattern in Repositories

```dart
Future<UserModel> login(String email, String password) async {
  try {
    final res = await _api.dio.post('/api/auth/login', data: {
      'email': email, 'password': password
    });
    return UserModel.fromJson(res.data['data']['user']);
  } on DioException catch (e) {
    if (e.type == DioExceptionType.connectionTimeout ||
        e.type == DioExceptionType.connectionError) {
      throw Exception('Could not connect to the server. Please check your API IP address.');
    }
    final msg = e.response?.data['message'] ?? 'Login failed';
    throw Exception(msg);
  }
}
```

## Authentication & Session

### Login Flow

```
1. User enters email + password
2. AuthViewModel.login() → AuthRepository.login()
3. POST /api/auth/login → { token, user }
4. SecureStorage.saveAccessToken(token)
5. SecureStorage.saveBiometricCredentials(email, password) if "Enable Biometric" was on
6. SharedPreferences.setBool('keep_me_signed_in', value)
7. POST /api/users/fcm-token to upload FCM token
8. notifyListeners → router redirect to /dashboard
```

### Multi-Step Registration

```
Step 1: /register
  - Form: full_name, email, password, student_id_no
  - POST /api/auth/register → OTP emailed
  - Navigate to /register/otp

Step 2: /register/otp (pinput widget — 6 boxes)
  - POST /api/auth/verify-otp
  - Response: { student, requires_profile_setup: true } for parents
  - Navigate to /profile-setup

Step 3: /profile-setup
  - Form: grade, class, admission_year, gender
  - POST /api/auth/complete-registration (server validates against Student record)
  - Response: { token, user }
  - Save token → /dashboard
```

### Session Restoration

On app launch (Splash screen):
```dart
Future<void> restoreSession() async {
  final token = await secureStorage.getAccessToken();
  if (token == null) return;          // → /login
  try {
    final res = await dio.post('/api/auth/refresh');
    user = UserModel.fromJson(res.data['data']['user']);
    secureStorage.saveAccessToken(res.data['data']['token']);
    notifyListeners();
  } catch (_) {
    await secureStorage.deleteAccessToken();
    // → /login
  }
}
```

### "Keep Me Signed In" + App Lifecycle

```dart
class AuthViewModel with WidgetsBindingObserver {
  @override
  void didChangeAppLifecycleState(AppLifecycleState state) {
    if (state == AppLifecycleState.paused) {
      final keepSignedIn = localStorage.getBool('keep_me_signed_in') ?? false;
      if (!keepSignedIn) {
        logout();   // app backgrounded without opt-in → clear session
      }
    }
  }
}
```

### Logout

```dart
Future<void> logout() async {
  try { await dio.post('/api/auth/logout'); } catch (_) {}
  await secureStorage.deleteAccessToken();
  await localStorage.clearProfileCache();
  await localStorage.setBool('keep_me_signed_in', false);
  user = null;
  notifyListeners();
}
```

## Local Storage Strategy

### Two Tiers

#### `flutter_secure_storage` (Encrypted)

Platform: Android Keystore + iOS Keychain

| Key | Value |
|---|---|
| `access_token` | JWT (renewed on refresh) |
| `biometric_enabled` | "true" / "false" |
| `biometric_email` | Saved email for fingerprint login |
| `biometric_password` | Saved password (encrypted at OS layer) |

#### `shared_preferences` (Plain)

| Key | Value | Purpose |
|---|---|---|
| `keep_me_signed_in` | bool | Whether to persist session on app backgrounding |
| `selected_theme` | string | (reserved for future dark mode) |
| `profile_cache` | JSON string of ParentProfileModel | Cache-first profile loading |
| `messages_inbox_<userId>` | JSON list of ThreadModel | Inbox cache |
| `messages_thread_<userId>_<contactId>` | JSON list of MessageModel | Thread cache |
| `fcm_token` | string | FCM token (uploaded to backend) |

### Cache-First Loading Pattern

```dart
// profile_viewmodel.dart
Future<void> loadProfile() async {
  // 1. Show cached profile immediately
  final cached = await localStorage.getString('profile_cache');
  if (cached != null) {
    profile = ParentProfileModel.fromJson(jsonDecode(cached));
    notifyListeners();
  }
  // 2. Fetch fresh in background
  try {
    final fresh = await repo.getParentProfile();
    profile = fresh;
    await localStorage.setString('profile_cache', jsonEncode(fresh.toJson()));
    notifyListeners();
  } catch (_) {
    // keep showing cached
  }
}
```

```dart
class FirebaseService {
  final _msg = FirebaseMessaging.instance;
  final _local = FlutterLocalNotificationsPlugin();

  Future<void> init({void Function(RemoteMessage)? onNotificationTap}) async {
    // 1. Request permission
    await _msg.requestPermission(alert: true, badge: true, sound: true);

    // 2. Init local notifications (Android channel + iOS settings)
    const androidInit = AndroidInitializationSettings('@mipmap/ic_launcher');
    const iosInit = DarwinInitializationSettings();
    await _local.initialize(
      InitializationSettings(android: androidInit, iOS: iosInit),
      onDidReceiveNotificationResponse: (response) {
        // tapped a local notification - bring to relevant screen
      },
    );

    // 3. Android notification channel (high importance)
    const channel = AndroidNotificationChannel(
      'high_importance_channel',
      'High Importance Notifications',
      importance: Importance.high,
    );
    await _local.resolvePlatformSpecificImplementation<
        AndroidFlutterLocalNotificationsPlugin>()?.createNotificationChannel(channel);

    // 4. Foreground listener (Android auto-displays in background)
    FirebaseMessaging.onMessage.listen(_handleForegroundMessage);

    // 5. Tap-from-background
    FirebaseMessaging.onMessageOpenedApp.listen((msg) {
      onNotificationTap?.call(msg);
    });

    // 6. Cold-start (app launched from notification tap)
    final initial = await _msg.getInitialMessage();
    if (initial != null) onNotificationTap?.call(initial);
  }

  void _handleForegroundMessage(RemoteMessage msg) {
    final n = msg.notification;
    if (n == null) return;
    _local.show(
      n.hashCode,
      n.title,
      n.body,
      const NotificationDetails(
        android: AndroidNotificationDetails(
          'high_importance_channel',
          'High Importance Notifications',
          importance: Importance.high,
          icon: '@mipmap/ic_launcher',
        ),
        iOS: DarwinNotificationDetails(),
      ),
    );
  }

  Future<String?> getToken() => _msg.getToken();
  Stream<String> onTokenRefresh() => _msg.onTokenRefresh;
}
```

## Biometric Login

### `BiometricService` (`core/services/biometric_service.dart`)

```dart
class BiometricService {
  final _auth = LocalAuthentication();

  Future<bool> canAuthenticate() async {
    return await _auth.canCheckBiometrics && await _auth.isDeviceSupported();
  }

  Future<bool> authenticate({String reason = 'Sign in to UniVerse'}) async {
    try {
      return await _auth.authenticate(
        localizedReason: reason,
        options: AuthenticationOptions(
          biometricOnly: true,
          stickyAuth: true,
        ),
      );
    } on PlatformException {
      return false;
    }
  }
}
```

### Flow

```
1. User toggles "Enable Biometric" on first login → saves email + password to secure storage
2. Next time login screen loads: AuthViewModel.tryBiometricLogin()
   - if biometric_enabled && credentials exist:
     - prompt biometric
     - on success: read creds → call login(email, password)
3. Settings screen has toggle to disable
```

`app/build.gradle.kts`:
- Java toolchain: **17**
- Compile/target SDK from `flutter.compileSdkVersion`
- Plugins: `com.google.gms.google-services` (Firebase)

```xml
<uses-permission android:name="android.permission.POST_NOTIFICATIONS"/>
<uses-permission android:name="android.permission.USE_BIOMETRIC"/>
<uses-permission android:name="android.permission.RECEIVE_BOOT_COMPLETED"/>

```

Single activity: `MainActivity` (singleTop launchMode).

### iOS (`ios/`)

- Standard Flutter iOS scaffold
- `Info.plist`: `NSFaceIDUsageDescription` for biometric auth
- `GoogleService-Info.plist` for Firebase
- Push notification capability must be enabled in Xcode
- Provisioning profile + signing identity required for builds

### Web / Desktop

Buildable in principle but **not configured or tested**. The QR scanner and biometric features won't work outside mobile.
